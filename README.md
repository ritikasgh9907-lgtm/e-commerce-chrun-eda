# 🛒 E-Commerce Customer Churn Analysis (EDA)

An in-depth Exploratory Data Analysis (EDA) project focused on identifying primary drivers of e-commerce customer churn using Python, Pandas, and Seaborn with a custom visualization palette.

## 📌 Executive Summary & Key Insights
1. **Complaints are the Primary Churn Driver:** Customers lodging complaints (`Complain = 1`) show a drastically higher churn rate.
2. **High-Risk Segment:** Unmarried/Single customers filing complaints represent the highest churn risk zone.
3. **Tenure Buffer:** Higher tenure significantly reduces churn probability among existing users.
4. **Retention Target:** New users making complaints need immediate customer success intervention.

## 🛠️ Tech Stack & Tools Used
* **Language:** Python
* **Data Manipulation:** Pandas, NumPy
* **Visualization:** Seaborn, Matplotlib (Custom Red Gradient Palette)

## 📁 Repository Structure
* `Customer_Churn_EDA.ipynb` - Complete Jupyter notebook with code, plots, and pivot analysis.
* `ecommerce_churn.csv` - Dataset used for analysis.
